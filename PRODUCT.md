# Product

## Platform

web

## Stack

TypeScript, Hono, Drizzle ORM, Turso (libSQL), Better Auth (вход через GitHub), React 19 + Vite + Radix Themes, MCP-сервер. Деплой — Vercel, автодеплой из `main`, домен `bus.akapps.click`. Репозиторий публичный: друзья-совладельцы присылают PR.

## Users

Совладельцы одного общего буса — компания друзей (число не фиксировано). Главная работа: сразу после поездки, стоя у буса с телефоном, записать, кто и сколько проехал. Реже — с ноутбука посмотреть, у кого сколько личного пробега и дней за год.

Админы — совладельцы, которые ведут список участников и раздают доступ. Первый админ задаётся в переменной окружения; админы назначают других админов в приложении.

## Product Purpose

Общий бортжурнал буса, которому все доверяют: каждая поездка записана один раз, видна всем и подписана автором.

Успех: после поездки запись делается за полминуты с телефона, и к концу года у каждого совладельца есть честные личные км и дни пользования — основа для будущего справедливого расчёта взносов.

## Positioning

Журнал — источник правды о личном использовании буса. По задуманной модели взносов личные километры потом оплачиваются по ставке износа, а личные дни определяют долю общих постоянных расходов. Поэтому важна не «красота журнала», а то, что пробег не теряется и не задваивается.

## Operating Context

- Поездка — личная (на конкретного совладельца) или общая (по общим делам).
- Пробег берётся по одометру «до/после» или вводится километрами.
- Если в поездке несколько человек или водителей, каждый отрезок записывается один раз.
- День личного пользования считается один раз на участника, даже если поездок за день было несколько.
- Отчёт ведётся по календарному году.
- Записывать можно за любого участника: совладелец без GitHub тоже учитывается, просто его записи вносят другие.

## Capabilities and Constraints

Сейчас (первая версия):
- вход через GitHub только для участников со связанным логином и для админов из переменной окружения;
- админка участников: имя, GitHub-логин, админ или нет, активен или нет; назначение админов;
- бортжурнал поездок: добавить, изменить, удалить; выбор года; личный и общий пробег; личные км и дни по участникам;
- деньги: стоимость поездки (амортизация + топливо + расходы в дороге) поровну на всех в машине, гости на пригласившем, «сам не ехал»; ставки периодами с даты, помощник амортизации; тип топлива; режимы «бак на бак» и учёт заправок по полным бакам с переводами; неучтённые км — на кассе; объяснение «Как посчитано»;
- **ключевая фишка — MCP**: каждый участник (не только админ) сам подключает ассистента (Claude, ChatGPT, Claude Code) по адресу `/mcp` со входом через GitHub и ведёт журнал разговором: «запиши поездку, 268 км, Казимеж». Подключение должно быть заметным и понятным в интерфейсе.

Позже, по ходу (не делать без запроса): обслуживание, бонус за обслуживание, калькулятор взносов, оплаты, выкуп долей.

Термины: бус, бортжурнал, поездка, общая поездка, личный пробег, одометр, участник (совладелец), админ. Валюта расчётов — злотые (zł).

## Evidence on Hand

- Реальных данных в репозитории нет. Не выдумывать реальных людей и цифры; демо-данные помечать как демо.

## Product Principles

1. Записать поездку быстрее, чем забыть: телефон, одна рука, всё, что можно, подставлено заранее.
2. Один журнал на всех: каждая запись видна всем участникам и подписана, кто её внёс.
3. Пробег честный: каждый отрезок — один раз, разрывы одометра видны.
4. Расти по ходу: код и схема простые, чтобы друзья уверенно присылали PR.

## Accessibility & Inclusion

Ввод на улице с телефона: читаемость при дневном свете, крупные цели касания, цифровая клавиатура для чисел. Интерфейс на русском.
