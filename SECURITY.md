# Безопасность

Нашли уязвимость — не открывайте публичный issue. Сообщите приватно: вкладка **Security → Report a
vulnerability** в этом репозитории. Ответим и починим, затем опубликуем исправление в релизе.

## Как устроена защита

- **Вход** — только через GitHub и только для участников. Участник привязан к неизменяемому числовому id
  аккаунта GitHub: если кто-то займёт освободившийся после переименования логин, он не войдёт.
- **Данные** закрыты сессией; права проверяются на каждом запросе — убранный или выбывший участник теряет
  доступ сразу. Меняющие запросы принимаются только как JSON и только со своего сайта (защита от CSRF).
- **Продакшен** отвечает только на https://bus.akapps.click; старые адреса деплоев `*.vercel.app`
  перенаправляются туда, запись через них отклоняется.
- **Заголовки**: CSP, запрет встраивания во фреймы (страницу согласия нельзя подсунуть в чужой сайт),
  `nosniff`, строгая Referrer-Policy.
- **Ассистенты (MCP)**: OAuth 2.1 с PKCE. Регистрация приложений без входа (так подключаются claude.ai и
  ChatGPT) ограничена 30 в час, брошенные регистрации удаляются через сутки. Страница согласия показывает,
  куда уйдёт доступ, и предупреждает, если это не Claude/ChatGPT/локальный клиент.
- **Превью PR** работают на отдельной базе с демо-данными и без боевых секретов; объём превью-базы ограничен.
- **Репозиторий**: защищённый `main`, CodeQL, поиск секретов с блокировкой пуша, Dependabot, CI для первого
  PR из форка запускается после одобрения владельца.
